# Smart Industrial Hazard Monitoring and Safety Response System

## Overview

This project was developed during my Embedded Systems Internship at CodeBind Technologies.

The system demonstrates the integration of Embedded Systems and Web Technologies for monitoring industrial safety parameters.

## Features

- Secure Login Interface
- Industrial Safety Dashboard
- Temperature Monitoring
- Distance Monitoring
- Intrusion Detection
- Alert Notifications
- Trend Analysis

## Technologies Used

### Hardware
- ESP32
- Ultrasonic Sensor
- LM35 Sensor
- LCD Display
- IR Sensor
- Buzzer

### Software
- HTML
- CSS
- JavaScript
- Arduino IDE
- Visual Studio Code
- GitHub
