# 🚨 Smart Industrial Hazard Monitoring and Safety Response System

A web-based industrial safety monitoring system designed to monitor
environmental and safety parameters and provide real-time alerts.

This project was developed during my Embedded Systems Internship at
CodeBind Technologies and combines ESP32 concepts with web technologies
to demonstrate an IoT-based industrial safety system.

---

## 📌 Overview

The system is designed to monitor different industrial safety parameters
using sensors connected to an ESP32.

The collected data can be displayed through a web-based dashboard,
allowing users to monitor safety conditions and identify potential
hazards.

---

## ✨ Features

- 🔐 Secure login interface
- 📊 Industrial safety dashboard
- 🌡️ Temperature monitoring
- 📏 Distance monitoring
- 🚨 Intrusion detection
- 🔔 Alert notifications
- 📈 Safety trend analysis
- 🌐 Web-based monitoring interface
- ⚡ ESP32-based embedded system concepts

---

## 🔧 Hardware

| Component | Purpose |
|---|---|
| ESP32 | Main microcontroller |
| LM35 | Temperature sensing |
| Ultrasonic Sensor | Distance monitoring |
| IR Sensor | Intrusion detection |
| LCD Display | Local information display |
| Buzzer | Safety alert |
